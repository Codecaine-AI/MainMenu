# Main Menu Pi Agent Chat Sidebar

This objective corrects the prior interpretation. The requested feature is a
classical Pi agent chat panel at the bottom of the editor left sidebar, backed
by the Pi agent SDK in Electron main.

The retained folder slug is historical; the implemented UI is not a PI Object
workspace and not a radial pie menu.
