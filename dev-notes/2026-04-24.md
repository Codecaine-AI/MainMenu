# Dev Notes — 2026-04-24

## Asset Extraction Pipeline: Two Key Insights

### 1. Background Removal Before Asset Extraction

Extracting individual assets directly from a busy/complex source image produces poor results. The background noise bleeds into each extracted piece, making clean isolation difficult.

**Better approach:** Use the image model to remove the background first, *then* extract each asset from the cleaned image. This two-step pipeline gives the model a much simpler task at each stage and produces significantly cleaner outputs.

- Step 1: Source image -> background removal -> clean composite
- Step 2: Clean composite -> individual asset extraction

This was observed directly with the Melee menu image, where the complex background made single-pass extraction unreliable.

### 2. SVGs for Complex Geometries + CSS Styling

Image models struggle to draw complex/unusual geometric shapes accurately. Instead of trying to render these as raster images:

- Represent complex geometries as **SVGs**
- Use **custom CSS** to style each SVG (colors, gradients, glows, animations, etc.)

This separates structure (SVG paths) from presentation (CSS), which:
- Gives precise control over shapes the model can't reliably draw
- Makes styling changes trivial without re-generating assets
- Keeps the rendering pipeline cleaner — the model doesn't need to handle every visual detail
